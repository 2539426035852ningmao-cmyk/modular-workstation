## 表面和状态

- `--shadow-recessed`：搜索占位表面顶部内阴影、底部细亮边；当前搜索尚未开放，不伪装为可用输入框。
- `--shadow-raised`：主按钮、上下文选中、强调模块卡片和深色 Rail 选中共用受光、薄厚度、接触阴影与柔和投影。
- `--shadow-panel`：其余面板更轻。浅色 Rail 米白选中使用适配深蓝底的轻阴影。
- Hover 通过表面变化或轻微亮度反馈；pressed 使用内阴影与 1px 下移；减少动态效果时不位移。没有常驻动画。
- Focus-visible 使用 2px 外圈，Rail 使用适合底色的独立前景；系统缩放可能产生像素取整。禁用控件使用实体中性底与明确文字，不靠整体透明度变淡。
- `.state-panel` 定义 neutral / loading / warning / error 的共用表面。应用目前仅展示真实空态；加载、警告、错误只有样式探针检查，没有编造异步业务或恢复流程。

## 结构和密度

保留四个真实导航入口、B 轻量模块首页。84px Rail、224px 上下文侧栏、70px 内容顶栏、28px 状态栏；使用原生系统窗口框，不绘制虚假的系统控制按钮。

视口不高于 1150px 时隐藏上下文侧栏，主要导航仍保留图标、可见标签及可访问名称；800px 以下模块变两列，600px 以下单列与 68px Rail，中文/英文在 200% 缩放时仍能使用。上下文侧栏目前只是只读页面信息，不宣称用户可折叠、调整或保存布局。主体可滚动，主要导航有自己的窄窗口滚动空间。

保持 Segoe UI / Microsoft YaHei UI、11/12/14/27px 字阶、4px 间距基础与 4/7/10px 圆角。图标以填充面和镂空结构为主，隐藏装饰 SVG 的读屏输出，按钮保留文字名称。

## 实际验证与边界

`npm test` 包含构建、类型检查、真实 Electron 导航和主题测试；96 个窗口案例覆盖中英文、四页、双主题、六组尺寸与缩放，实际可见文字最低对比约 4.58:1。报告和截图见 [运行证据](design/previews/runtime/validation.json)。此检查不能替代屏幕阅读器、系统高对比模式和多显示器 DPI 人工验证。

主题继续跟随系统，没有引入手动主题配置或持久化。新建工作空间、搜索、文件管理、插件安装、任务中心均未实现；首页模块卡片和主操作只导航到真实页面，空态中的业务按钮禁用且说明原因。没有样稿中的文件、任务或假完成记录。S0/S1/S2 关卡及最终产品验收仍按原流程。
