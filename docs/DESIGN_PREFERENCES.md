## 每次视觉修改交付前复查

- 对照本次截图指出的区域，确认修改来自共用样式，没有只修单张截图。
- 检查深浅主题、普通/选中/键盘焦点与窄窗口；文本仍清楚，填色没有侵入业务内容。
- 更新生成稿与预览，执行对应静态验证；不得将设计验证写成应用功能已实现。
- 将新的明确反馈同步到本表、D1 和相关修订记录；先查现有记录，不重复向用户确认已决定的偏好。

这份文件记录确认的局部偏好，不代表全部页面已完成最终视觉验收，也不批准切换组件库或实现未排期功能。应用尚未映射这些静态设计；实际进度以 Issue / PR 为准。PR 合并前，新会话还须读取 PR 分支，不能假定 main 已包含本记录。
