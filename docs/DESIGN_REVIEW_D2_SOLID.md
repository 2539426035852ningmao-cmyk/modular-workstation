## 已确认偏好与实际修改

用户指出原选中态主要依赖浅底和细边框，视觉单薄；要求颜色填满，以面型为主并结合线条，让图标与状态更扎实。本次将此偏好写入 [D1](DESIGN_PROPOSAL_D1.md)，不重新询问已经确认的方向。

| 区域 | 本次修订 |
| --- | --- |
| 全局导航 | 选中入口整块钴蓝 `#2563EB`，白色图标与文字；保留短标签 |
| 资源树 / 插件分类 | 当前行实色填充，图标、文字与数量使用白色前景 |
| 标签 / 视图 / 筛选 | 活动标签、网格按钮、插件筛选与审阅情境均改为完整填色 |
| 选中素材卡 | 卡片信息区填蓝、文字白色；缩略图内容保留原色与比例 |
| 普通次要按钮 | 使用实体中性底面，仍与蓝色主操作区分 |
| 图标 | 实色面为主，以镂空、局部透明面和少量线条表达结构；统一光学尺寸 |
| 警告 / 错误 | 按用户补充要求，警告采用红色实体提示块；错误也保持红色，独立语义 Token、图标和文字继续区分风险与失败 |

仍保留 B 轻量首页、钴蓝、原有布局与密度；未将全部表面涂成强调色。箭头、加号、关闭及文字辅助符号保留适当线条，主图标不再只有轮廓；原文件、缩略图与业务内容不因选择而被重新着色。焦点有独立外圈，选择状态不替代键盘焦点。

用户随后明确警告应为红色，先反馈首版过亮、饱和度过高，又指出暗灰红显脏。当前候选回到纯红色相，只轻度降低原版饱和度，使用 `#C93B3B` 与白色图标，两种主题一致；风险文字在深色用 `#F2A5A5`、浅色用 `#B23535` 保证可读性，不保留原金黄色。状态块有独立的两项共用 Token，原 23 个主题变量仍保留。图标与文案仍说明具体情况，红色不代表文件已经损坏或数据已经丢失。

## 普通边框减弱与长期留存

产品负责人确认当前填色、图标和红色方向，进一步指出普通轮廓过粗、过亮。本次保留 1px，统一将搜索框、次要按钮、视图切换外框、未选中审阅标签的边框色设为原边界色的 50% 不透明度。控件底面和文字不降低透明度，实色选中与独立键盘焦点保持清楚。主区域原有安静分隔线不额外增强。

所有已确认反馈汇总于 [视觉偏好与复查清单](DESIGN_PREFERENCES.md)，AGENTS.md 已加入界面修改前必读要求，D1 和项目恢复入口同步链接。记录随仓库及 PR 留存，供未来会话复查；不是依赖聊天中的临时记忆。

## 来源与维护

覆盖四类主稿的深浅主题，以及三类状态稿的深浅主题，共 14 份界面源稿，并同步主题审阅标签。图标为项目自绘 SVG，没有引入第三方图标依赖或 Morphicons 动效。

- [共享视觉处理](design/solid-visuals.cjs)：统一选中表面与图标符号，重复执行不会追加重复样式。
- [浅色生成器](design/generate-d2-light.cjs) 从对应深色稿与 D1 生成；[状态生成器](design/generate-d2-states.cjs) 在生成时复用共享处理。
- `--color-accent-solid` 与 `--color-on-accent` 承担实色选中；`--color-selected` 保留为轻量上下文底面，不再代表所有活动控件的填色。仍使用原 23 个候选主题变量。
- 调整共享图标或样式后，先运行 `node docs/design/solid-visuals.cjs` 更新四份深色主稿，再生成浅色和状态稿、重新导出预览；不要手改生成的 HTML。

## 本次实际验证

- [实色专项记录](design/previews/d2-solid-validation.json)：15 份审阅源中，43 个选中表面的真实计算样式均为不透明钴蓝、白色前景，文字对比度约 **5.17:1**；76 个核心图标定义检查具有实色面，不再只描边。
- 本轮新增 55 个可见普通边框的计算样式检查：均为 1px、50% 边框色透明度，控件本身不透明、文字未随边框淡化；原有实色选中检查继续通过。
- 已重新执行首页、素材、插件深色导出检查：共 20 个静态布局案例；浅色 24 个布局案例、58 组原主题配色检查；首页的 116 组双主题配色检查也重新执行。
- 已重新执行状态稿的 168 个静态案例、36 个键盘选择案例；主题审阅页的四个页面选择、八张图片加载与窄窗口检查通过。完整记录仍在各自设计说明中。
- 全部现行主稿和状态稿预览重新导出；人工查看深浅首页、素材选中卡、失联状态与窄图、插件稿及汇总图。未使用用户标注截图作为项目资产，项目内只保存自有设计导出。
- 验证属于静态设计；没有新增应用依赖，没有修改 `src`/Electron/锁文件，没有重跑应用构建、运行、打包或安全隔离测试。不能把填色样式视为真实业务或 Morphicons 接入完成。

专项检查可运行 `node docs/design/verify-d2-solid.cjs`。其他导出与布局复现命令沿用 [主稿说明](DESIGN_REVIEW_D2_LIGHT.md) 和 [状态稿说明](DESIGN_REVIEW_D2_STATES.md)。
