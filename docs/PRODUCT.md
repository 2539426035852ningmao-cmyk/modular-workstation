# 产品基线（PRODUCT）
版本：V0.1（规划基线，2026-10-19）｜状态：已通过需求访谈，技术实现未定稿

## 1. 产品愿景
免费开源、Windows 优先的模块化个人工作站：通过统一专业桌面工作空间连接项目、文件、工具、插件与自动化。适合广泛个人电脑用户；普通用户开箱即用，专业用户可配置工作区，开发者能借助官方 SDK 与 AI 开发插件。

## 2. 已确认需求（变更必须记录决策）
- 定位：模块化个人创作与生产平台，而非单一 AI 软件；工作站作为通用个人工具平台，兼顾 AI 创作、项目及素材、工具入口、跨插件工作流。
- 目标平台：Windows 桌面优先；Windows 11 为安全验证主基线，Windows 10 的兼容性与支持边界需单独说明；将来可扩展平台但本期不承诺。
- 受众：广泛个人电脑用户，不只 AI 创作者。
- 视觉：专业创作软件结构为主，现代精致体验为辅；专业 C + 现代 B；品牌视觉作为设计工作的一部分，最终命名未定。
- 导航：固定 Shell / 全局导航 + 可切换工作空间；专业页面可停靠和调整面板，提供布局预设、保存与恢复；限制不可控的完全自由。
- 主题：深浅双主题；先精细打磨深色，浅色按完整主题验收，须可访问且适配缩放。
- 开发：AI 编程工具主导，Codex 主编码、Gemini 独立审查、ChatGPT 协调设计和验收组织；最终产品决策与发布由用户确认。
- 数据：本地优先、离线可用、可选云端；不强制登录。
- 文件：原位置关联索引 + 复制导入工作站管理目录；删除引用和删除源文件必须严格区分。
- 插件：轻量功能、独立应用、跨插件协作的深度扩展；插件安装、权限、生命周期、SDK、UI 规范统一。
- 插件生态：官方和核心永久免费开源；第三方自由选择开源/闭源与免费/收费；支持本地安装与开发者调试，未来可选插件目录/市场。
- 权限：最小权限默认；官方/审查插件仍遵循必要授权；用户可选择高信任模式，显著提示原生代码执行风险，权限可见且可撤销。官方与审查并不自动等于完全可信。
- AI 插件开发：标准 SDK、模板、AI 可读规则、自动校验；外部 AI 工具先行，未来工作站内自然语言开发界面。官方插件使用相同工具链。
- AI 模型：统一服务层，兼容云端、本地和第三方；凭据隔离，插件通过规范接口调用。
- Web：本地插件 + Web 技术插件 + 外部网页工具；无法安全内嵌的外部网页用系统浏览器打开。
- 性能：基础程序轻量、专业功能按需加载，保持稳定可用；所有基准指标必须真实实测，不能凭猜测宣称。
- 初始体验：精选核心基础工具 + 自由扩展，避免空壳和臃肿预装。
- 语言：中文优先，国际化从第一天设计；英语首批逐步完善，插件使用同一 i18n 机制。
- 商业：主程序与官方插件完全免费开源。当前不建设支付/收费系统。
- 第一阶段优先：工作站 Shell、主题、导航、插件安装管理与示范插件闭环；第一个官方标杆插件为通用文件与素材管理。

## 3. 关键用户路径（首批必须完整）
1. 首次启动 → 认识界面 → 无登录情况下创建或打开本地工作区。
2. 发现/导入插件 → 兼容与来源检查 → 查看权限 → 安装 → 打开 → 更新/禁用/卸载。
3. 关联文件夹或导入文件 → 后台索引 → 搜索/预览 → 对文件执行安全操作 → 通过插件处理。
4. 面板调整 → 保存布局 → 重启 → 恢复布局/默认布局。
5. 网络不可用/插件损坏/文件失联时获得明确错误提示及恢复操作。

## 4. 非目标（第一公开测试版以前）
- 大型云同步与在线账号体系；付费商城；全功能 AI IDE；无限制系统插件权限。
- 直接开发所有音视频工具或复杂节点式工作流。
- 未通过安全验证就将任意远程 HTML/JS 加载为高权限插件。
- 仅以视觉截图或假数据替代可操作功能。

## 5. 产品验收原则
每一个页面必须有真实入口、空状态、加载状态、失败状态、键盘/鼠标体验；功能流程能够被独立复现。新需求先写 Issue，再评估优先级与依赖；重大改变通过 docs/DECISIONS.md 留痕。阶段顺序以 docs/ROADMAP.md 为准；实际任务状态以 GitHub Issues/Projects 为准。
