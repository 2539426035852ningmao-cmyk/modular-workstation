# S2-03 统一命令入口

关联 [#34](https://github.com/2539426035852ningmao-cmyk/modular-workstation/issues/34) 分支 feat/s2-command-palette 尚待所有者体验验收

## 实际行为

顶部查找命令按钮或应用内 Ctrl K 打开原生 HTML dialog 不是新系统窗口 不注册 Electron globalShortcut 不影响其他应用
先支持首页 工作区 插件 设置四个既有页面 命令与左侧导航共用列表和切页动作 不表示插件安装或文件搜索已实现
输入按空白拆词 所有词须在名称 分组或关键词中匹配 忽略大小写 支持中英文关键词 无匹配时显示真实空结果
上下键循环选择 Enter 打开选中页面 Escape 关闭 Tab 约束在模态内 查询保留且再次打开全选 点击结果也能执行
关闭使用浏览器原生焦点恢复 然后才导航 输入法组合期间 Enter 不执行 Escape 不关闭 快捷键不在组合输入事件中触发
2026-10-22 中文优先修订 组合期间 Enter 不取消原生确认行为 只有独立的非组合 Enter 才打开页面 Escape 的面板关闭保护继续保留
查询只保留在当前运行进程 不保存到磁盘 不发送网络 不增加 IPC 系统进程或任意脚本执行权限

## 源码复用

Fluent-Qt v1.10.2 / 4d8a600112a6c43bb7bd0c7cdb5b08185ad759ac 的 CommandPalette.h/.cpp 匹配与动作借用行为移植到 React
Qt QAction 对应既有页面动作 使用 HTML dialog 实现模态和焦点 复用自绘图标 双语 Token 与深蓝实色选中 没有复制 Qt 运行时 字体或 Gallery 资产
适配范围和完整 MIT 许可见 [第三方声明](../THIRD_PARTY_NOTICES.md) 不能把这项称为原生 Qt 控件已直接集成

## 验证与边界

tests/command-window.test.cjs 先在旧版入口复现失败 再覆盖鼠标执行 键盘 组合输入 模态焦点 多词与空结果 双语 双主题 1440 与缩放后 400 宽截图
tests/chinese-command.test.cjs 覆盖 Enter 默认处理未取消 三种组合识别路径 中文和全角空白匹配 以及通过 Chromium CDP 发起和提交真实浏览器引擎组合文本 不控制系统鼠标或更改 Windows 输入法
该验证不是微软拼音 搜狗 微信输入法等原生候选窗口的完整实测 不声称已覆盖所有输入法 仍保留最终用户中文体验验收
scripts/verify-package.cjs 使用实际候选 exe 再运行完整命令检查 不只测试源码渲染器
自动测试继续隐藏运行 原生窗口可见检查只在隔离云端 没有执行的验证不得写通过
没有异步检索任务 因而没有伪造加载进度或请求失败态 现有页面自己的加载 保存与错误流程保持原样
当前均为固定可导航页面 没有动态插件命令注册或可撤销异步命令 功能扩展时再评估启用状态和生命周期
撤销本 PR 恢复原顶部占位和原导航 不改 appearance 或 workspaces 文件 不新增依赖

工作空间中文命名同样保护组合 Enter 不误建空间 提交候选词后另按 Enter 才创建 复用同一后台中文检查文件 不取消原生选字默认行为
