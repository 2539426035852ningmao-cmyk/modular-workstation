## Codex 事先独立方案

保持 Electron/React/TypeScript 候选 Shell 只加载本地构建内容 禁用 Node 集成 开启隔离 sandbox 和 CSP 禁止页面跳转和新窗口。不增加插件 IPC 文件或网络业务。复用现有主题和翻译 不重设计已验收视觉 不将原型算作 S2 或插件安全隔离完成。

Codex 事先列出的待查事项包括英文 DOM 语言 测试监听覆盖和快照陈旧。后续核对 src/main.tsx 第 5 行及真实运行确认 documentLang=en 正确 因此撤回 DOM 语言可能未同步的疑点；英文原生窗口标题仍为中文是另一项真实问题。启动请求监听在 firstWindow 之后注册 仍不能将零记录扩展为整个启动期间的网络审计。

## 独立意见与协调裁决

| Gemini 意见 | Codex 复核及裁决 | 处置 |
| --- | --- | --- |
| @electron/asar 直接导入但未直接声明 中危 | 确认缺少直接声明 当前 npm 锁定安装可正常解析 严格隔离安装失败未实测 因此降为可移植性维护风险 不是已复现的当前构建失败 | 在 #5 工具链与干净安装核验时评估显式声明 |
| 英文原生窗口标题仍为中文 低危 | 已启动 Electron 注入 en-US 并重载 页面标题英文 DOM lang=en 原生标题仍中文 真实复现 | 记录为 S1/Shell 双语余项 不阻断审查流程 |
| generic 搜索占位容器带 aria-label 低危 | DOM 确认无 role 且有 aria-label 采纳冗余语义问题 可保留可见 span 文本 不为占位搜索伪造交互 role | 后续 Shell 语义小修 读屏与 AXE 未实测 |
| 侧栏 h2 在主区 h1 前即构成缺陷 | 不采纳这一判据 W3C 明确给出导航和侧栏 h2 在主区 h1 之前的有效结构示例 不能据此移除语义标题 | 不修改现有标题结构 |
| 无阻断性安全或架构问题 | 仅采信为所给快照内未发现阻断问题 不是安全认证 报告未读 CSS/Icons 因而不采信其中完整视觉映射的强结论 | 其余未审范围保留 |

W3C 对照：[固定侧栏及主标题后置示例](https://www.w3.org/WAI/tutorials/page-structure/headings/) / [generic 命名限制](https://www.w3.org/TR/wai-aria-1.2/#generic)。
