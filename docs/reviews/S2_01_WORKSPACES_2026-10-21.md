### 未采纳或降级并说明原因

- 保存原文件失败后继续重置 被拒绝 原字节保留优先于解锁界面 recover 的拒绝由主 IPC try await 和前端 request try await 捕获 不是未处理异常 外部移除文件后可点重新读取 单元测试已验证无需重启 仍被锁定的文件应保持阻断
- 大写 UUID 兼容当前没有来源 主进程生成的 ID 全为小写 未开放外部导入或原生客户端 不新增未经排期的迁移承诺
- 0o600 不是 Windows ACL 安全隔离 采纳为文档限制 不建设新的系统权限服务
- 放宽来源至 URL 前缀或任意查询 未采纳 当前无 hash 路由 同一 entry 用于 loadFile 与精确比较 实际 Windows 源码与打包调用均通过 更多路径变体列为兼容性待验证 不能用推测扩大授权
- 缺少 bridge 会抛出未捕获异常 未成立 action 在 request 的 try 块内调用 同步 TypeError 也会被捕获
- 重置造成 activeTab 不在 tabs 未成立 主进程完整验证并同时重置 view 前端接收整体状态 现有恢复与重置实测覆盖
- 快速操作覆盖布局 作为后续自动调用方风险保留 当前交互在 busy 时禁用 主进程串行提交 调用方须等待确认 不声称支持未实现的多控制端实时协作
- 错误导航到工作区 是已确定的异常可见性策略 保留 否则隐藏组件中的恢复入口无法被用户看见
- 返回工作站后再次关闭还会确认 是保护尚未保存操作的预期行为 成功保存后会清除失败标记 若原生确认本身失败 则保留窗口让用户重试 不采用异常时强制退出的建议
- 次实例临时注册处理器 属于进程退出前的短暂内存 没有窗口与数据写入 不为此引入强制进程终止
