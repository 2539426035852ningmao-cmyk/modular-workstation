| 发现 | 裁决与证据 |
| --- | --- |
| 恢复默认写入失败后主文件消失 | 首轮有效问题 先加失败测试复现 ENOENT 改为 COPYFILE_EXCL 复制保留再原子替换 失败仍保留原路径与 CORRUPT 状态 测试现通过 |

| 设置卸载后 setState 必然警告泄漏 | React 19 下未证明该结论 主进程拥有保存生命周期 页面重挂读同一串行队列 不将旧 React 警告假设作阻塞项 |
| 后台二次启动抢焦点 | 无独立目录启动已在锁前退出 测试始终临时目录 仍增加第二实例 argv 防御 避免显式复用目录时唤醒正常窗口 |
| ready-to-show 快速竞态 | 监听确实在 loadFile 前安装 原文先后顺序假设不成立 不增加可能打扰用户的兜底弹窗 |
| 重复恢复失败留下多个备份 | 非阻塞 保留每次显式尝试的原字节优先 文件每次读入限制 4KiB 不擅自删除用户诊断记录 提醒持续失败应先处理磁盘或权限 备份可人工清理 |
| 复核声称 appearance:load 不同步 nativeTheme | 驳回 area==='appearance' 对 load/change/recover 均同步 其引用代码本身已表明该条件 |
| 退出期间 CLOSING 响应 | 预期协调逻辑 新 IPC 在关闭等待期间拒绝 防止队列尾后新增保存 取消关闭后恢复请求 |
