# 开发路线图（ROADMAP）
版本：V0.2｜2026-10-19｜时间估计暂不承诺（先完成技术原型）

## 项目运营规则
- GitHub Issues = 任务目标、依赖、验收、实施证据。
- GitHub Projects「模块化工作站 · 开发总控」= 开发队列与任务实时状态。
- PROJECT_STATE.md = 跨会话恢复的短快照（**非自动实时同步**，必须检查链接）。
- 同一开发周期保留一个唯一主任务；其他 Issue 允许排队，不等于同时开发。
- 需求变更先记录影响与依赖；未经关卡验收不得宣布进入下一阶段。
- 详细交接与进度维护步骤参阅 [OPERATIONS.md](OPERATIONS.md)。

### S3 插件 SDK、隔离与生命周期 MVP
交付：清单/SDK、受限运行时、权限服务、安装/激活/禁用/卸载/升级、开发模板与验证器。
门槛：无须编辑主程序源码即可安装独立插件；未经授权不能获得高权限；常见故障可隔离恢复。

### S4 官方文件与素材管理插件
交付：原位关联与导入双模式、后台索引、搜索、缩略图、预览、批量操作及文件失联处理。
门槛：真实文件端到端测试通过，删除引用与删除原文件明确区分，能恢复异常。

### S5 首个公开测试版与发布质量
交付：CI、版本/发布策略、安装与升级、异常恢复、兼容与性能报告、开源贡献说明。
门槛：相关发布检查通过，用户批准；PR 已合并不等于产品验收通过。

### S6 长期生态
交付：统一 AI 模型服务、跨插件工作流、插件目录/审核、更多官方插件、内置 AI 插件开发中心。
门槛：SDK 版本化、安全与数据隔离及真实复用验证。
