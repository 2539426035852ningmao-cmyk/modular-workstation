## 3. 13 项决策与当前代码的对应

| 决策 | 可复用基础 | 缺口、冲突风险与后续落点 |
| --- | --- | --- |
| D01 统一 Shell | 主程序拥有导航、主题与窗口 | 未来用受控容器及声明式入口接插件，不允许插件接管全局界面 |
| D02 多标签与受约束分屏 | 四个页面入口和主内容区域 | 当前单个 `PageId` 不代表标签模型；S2 新增工作空间/标签/布局关系，数量与尺寸仍待验证 |
| D03 各工作空间布局记忆 | 暂无持久化包袱 | 布局数据与业务文件分开；版本迁移、预设、重置不删除用户数据 |
| D04 正常会话恢复 | 可以复用 Shell 启动入口 | 持久化工作空间/标签描述，按需激活插件；恢复界面不能自动重发付费或覆盖操作 |
| D05 异常恢复与安全启动 | Electron 主进程可以承担启动协调 | 需区分正常/异常退出及恢复循环；安全启动不自动激活可疑第三方插件 |
| D06 未保存保护 | 未来可由 Shell 统一关闭入口 | 当前无业务数据、无保存协商；以后不能直接套用当前窗口退出流程，失败/无响应不视为已保存 |
| D07 插件故障隔离 | 当前 renderer 已禁 Node、启用 contextIsolation/sandbox | 这些设置不证明插件安全隔离；需宿主边界、故障标签、诊断及受控重启，另做安全验证 |
| D08 资源监控 | 主进程可作为未来协调位置 | 尚无计量；区分可归属/共享资源、正常高负载及异常，不虚构精度或随意杀任务 |
| D09 统一任务中心 | 状态区设计可以保留为入口候选 | SDK 声明进度和可用操作，插件执行/保存结果；取消要确认，未知进度不能假装百分比 |
| D10 关闭与后台 | 可复用原生窗口生命周期 | 当前非 macOS 窗口全部关闭后直接退出；有真实任务后需关闭协调及托盘能力，仅支持的任务可后台运行 |
| D11 中断与手动恢复 | 暂无自动重试行为 | 最小任务记录、执行方任务 ID、可恢复能力与用户继续动作；云端先查询原任务，避免重复费用 |
| D12 统一资源交换 | 当前没有任意文件权限桥接 | 设计资源引用/托管副本模型、受控访问服务与 SDK；传递引用不能自动转授权限 |
| D13 最小授权与撤销 | 可沿用仓库最小权限硬边界 | 按插件/资源/操作/期限授权，并在每次访问执行检查；读、写、覆盖、删除分开，撤销不能追回已读出数据 |

整体兼容，没有理由推翻原型；上述缺口不能用静态 UI 填充后宣称完成。未来接口字段、存储方案与宿主技术均需对应任务的小范围技术提案、性能/威胁评估和测试。布局迁移需备份与版本策略；权限及任务协议需兼容策略；恢复入口需安全启动回退。不得用回滚程序版本代替用户数据恢复。

## 4. 图标优化候选（Proposed，尚未接入）

后续用户已明确要求实色选中、面型为主并结合线条。下文是本次同步时的初始候选，线宽等建议已由 [实色与图标修订](DESIGN_REVIEW_D2_SOLID.md)更新；实际应用仍未接入，图标族与 Morphicons 技术采用未因此自动批准。

保留 LobeHub 克制视觉、Figma 工作区结构、B 轻量首页与已选钴蓝。图标负责清楚辨识入口；导航不因悬停不断变形。

| 位置/语义 | 候选造型 | 优化目标 |
| --- | --- | --- |
| 概览 | 房屋轮廓 | 替代编号，保留入口文字与选中状态 |
| 工作空间 | 双区域面板 | 与首页、文件夹区分，不暗示已支持高级停靠 |
| 文件素材 | 文件夹 | 展开/收起可使用同语义状态图标 |
| 插件 | 拼图块 | 替代容易理解为“新增”的十字造型；新增仍用加号 |
| 设置 | 对称齿轮 | 统一光学尺寸与线宽，避免不规则轮廓 |
| 任务/权限 | 清单 / 盾牌 | 作为未来明确标注的入口或状态，不暗示引擎、隔离已实现 |
| 关闭/折叠/重试 | 叉号 / 箭头 / 回转箭头 | 关闭与取消、重试与继续区分，保留文字提示 |

当前静态规范：24×24 坐标、同一图标族；依据后续用户反馈，以面型为主、线面结合，使用实色轮廓与镂空细节。导航建议 20px，紧凑工具栏 16px；可点击区域与图标本体分开。选中使用实色钴蓝填充、白色前景及 `aria-current`；仍需验证不同显示尺寸与 Windows 125%/150%/200% 缩放的清晰度。装饰图标隐藏于辅助技术，图标按钮须有稳定可访问名称、焦点与提示。

### Morphicons 的采用边界

已读取 [官方文档](https://www.morphicons.com/docs) 与 [机器可读说明](https://www.morphicons.com/llms.txt)。Morphicons 是 SVG 变形引擎，静态图标数据需另外选择；Lucide 为候选图标族，尚未批准或安装。引擎 MIT 与图标来源许可分别核验，不能把引擎许可套在所有图标上。

- 优先试验同一控件的真实状态转换：菜单/关闭、复制/确认、文件夹展开/收起。成功态必须来自执行结果；不把点击瞬间当成功。
- 无空闲循环、不弹跳导航、不靠变形表达危险操作；图标名称、焦点与控件位置保持稳定。时长/弹簧手感经实际样例评审，不把官网演示参数直接定为产品标准。
- 官方 `reducedMotion` 默认为 `never`；若采用必须显式设为 `user`，跟随系统偏好并保留即时静态反馈。复制/确认的动画状态也不能覆盖实际错误。
- React 接口的数据输入不同于 React 图标组件；先做单控件试验，检查离线打包、许可、增量体积、快速连续操作、卸载清理、键盘/读屏及减少动态效果，再决定是否引入。
- 本次没有新增依赖、修改应用或播放真实 Morphicons 动画；这些检查尚未执行。采用失败时可退回同一图标的静态状态，不改变业务逻辑。
